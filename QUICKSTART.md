# 🚀 Quick Start Guide - Digital Marketing Bot

## ⚡ Get Started in 60 Seconds

### Step 1: Start the Bot
```bash
npm start
```

### Step 2: Open in Browser
Click this link or copy-paste to your browser:
```
http://localhost:3000
```

### Step 3: Start Chatting! 💬

Type your marketing question and press `Ctrl+Enter` or click the Send button.

---
